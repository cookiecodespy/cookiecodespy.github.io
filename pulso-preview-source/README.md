# Pulso Santiago · mobile design preview
This is a **frontend-only public review copy** of the React/Vite interface from `cookiecodespy/pulso-santiago` (private canonical repo).
It is deployed to `https://cookiecodespy.github.io/pulso-santiago/` by GitHub Actions.
**Not** the private functional Sites D1/R2 application. No citizen reports, photos, news database, admin credentials, or private API keys are copied. No public backend is configured, so real submissions/login are intentionally disabled, and news do not load.
The source snapshot is for visual/mobile review only. It is not a production citizen launch. The portfolio `index.html` remains untouched.
