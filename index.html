Project DONNA

persistent personal AI // local-first // capability-gated

My personal AI system built around Hermes Agent + a local Gemma model served through Ollama. DONNA is designed as a durable operator, not a stateless chatbot: memory, explicit capability boundaries, failure classification, regression tests and a control plane that separates what the model says from what the system actually executed.

The core rule is simple: DONNA does not gain a capability because a tool exists; it gains it after proving it can use it safely.

02 // method

How I build.

The aesthetic is hacker-ish. The engineering principle is the opposite of chaos: bounded permissions, reproducibility and visible failure.

01 / reality

Real workflows first.

Products and agents should touch actual constraints: files, APIs, users, infrastructure, latency, messy data and failure states.

02 / proof

Leave a receipt.

A claim is stronger when there is a test, metric, commit, log, source link, screenshot or reproducible path behind it.

03 / capability

Earn permissions.

New tools are gated by evaluations and narrow boundaries. Capability growth should be measurable instead of assumed.

04 / authority

Human stays in charge.

Automation can execute aggressively inside a defined scope while consequential actions remain reviewable and attributable.

03 // evolution

One idea, iterated.

The personal-assistant project has changed names and runtimes, but the underlying goal stayed consistent: a durable technical partner that can understand context and actually operate tools.

early build

JARVIS / Alfred experiments

Desktop assistant work combining multiple model providers, persistent conversation, command execution, voice input/output and a terminal-like interface. The early phase was broad and feature-heavy; it established the direction.

2026

OpenClaw Personal Ops

Moved from building every primitive myself to adapting a stronger agent harness. The assistant became an operations layer for files, commands, deployments, memory and repeatable skills.

current

DONNA

The focus shifted from “more features” to trustworthy agency: local inference, explicit capabilities, test gates, incident classification and a path toward controlled delegation to specialist agents.
